# Character asset

`makehuman-base.obj` is the MakeHuman community base mesh (hm08), downloaded from the official project repository:

- Source: https://github.com/makehumancommunity/makehuman/blob/master/makehuman/data/3dobjs/base.obj
- Asset license: CC0, as stated in the asset header and the project's asset license page.
- License information: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md

The simulator loads the mesh's body and eye geometry only. It transforms and crops the body to an upper bust at runtime. The mesh is not a photo texture; the editable haircut surface and contact-length field remain separate simulator geometry.
